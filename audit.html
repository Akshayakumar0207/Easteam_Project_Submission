Daydream Skirt: audit and write-up

Practical task by Akshaya Kumar. Product page reviewed on easteamny.com, the five biggest improvements ranked by how much they help someone buy, with the number one fix built as a clickable page.

Top 5 improvements, ranked

  1. Size, stock and delivery information is unclear. Shoppers see "In Stock / Make to Order / Notify" with no explanation and no delivery date, so they can't tell when it arrives. This is the biggest cause of hesitation at the buy button.
  2. Shipping and returns are buried in an accordion. The returns policy (7 days, store credit only) is a real concern for buyers. It should sit next to the Add to Cart button.
  3. Pricing is inconsistent. The page shows $202, the homepage shows "From $192", and the cart says "20% off applied, no code needed". Differing numbers lose shopper trust.
  4. Product details contradict themselves. The description says a high-stretch spandex blend, but the material line lists only "Yarn 50% Dacron 35% Cotton 15%". Colour names also differ: the swatch says "Porcelain Dream" while the product says "Porcelain White".
  5. Missing fit help and social proof. Only a plain size guide link, with no model height, size worn or reviews on the page. Shoppers buying a fitted mini skirt need fit information.

The number one fix

  • Each size shows its own status: in stock, made to order or sold out.
  • Tapping a size updates the availability message, the delivery date range and the button. A sold-out size turns the button into "Notify me".
  • Delivery, shipping, returns and fit sit directly under the button, so no one has to open an accordion or leave the page.
  • The layout follows EASTEAM's page: announcement bar, black navbar, two columns, a sticky Add to Cart bar on mobile. The look stays refined and feminine: blush, plum ink, serif headline, rose accent.

Delivery dates and the made-to-order lead time are sample values. In a real build they would come from Shopify inventory and shipping rules. Product images are illustrations; real photography would replace them.

Process

  1. Opened the live product page and homepage and noted every point where a shopper might hesitate.
  2. Ranked the issues by how close they are to the buy decision.
  3. Designed the buy box for the number one fix, then built the full page as clickable HTML so the size states can be tried.
  4. Kept the visual style close to the existing brand colours and layout.
